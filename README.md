\# 🎬 Movie Database System



This project is a web-based Movie Database System developed using \*\*PHP\*\* and \*\*MySQL\*\*.



\## 📌 Features



\- Add Actor details through input form

\- Add Movie details (title, year, genre, director, length)

\- Store data in MySQL database

\- Search movies by year range

\- Display movies with:

&#x20; - Title

&#x20; - Genre

&#x20; - Year

&#x20; - Director

&#x20; - Production Company

&#x20; - Length

\- Display directors who act in their own movies

\- View tables (Actors, Movies, Genres, Directors)



\## 🛠 Technologies Used



\- PHP

\- MySQL (phpMyAdmin)

\- XAMPP

\- HTML/CSS



\## 🗄 Database Structure



Main tables used:

\- Actor

\- Director

\- Movie

\- Genre

\- ProductionCompany

\- MovieActor

\- MovieDirector

\- MovieGenre



\## ▶ How to Run the Project



1\. Install XAMPP

2\. Start \*\*Apache\*\* and \*\*MySQL\*\*

3\. Copy project folder to:



C:\\xampp\\htdocs\\

4\. Open phpMyAdmin and create database:



movie\_db

5\. Import or create tables

6\. Open browser and run:



http://localhost/movie\_project/



\## 📊 Outputs



\- Movie search by year range

\- Director acting in own movie report
